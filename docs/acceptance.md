# HKPortalAdmin 驗收清單

先備份測試資料，記錄一篇測試文章 UID。全部操作僅在測試資料庫執行。

- 未登入開啟後台與任一讀寫端點：Windows 驗證 challenge；已登入可存取。無防偽 token 的 POST 被拒絕。
- 三種介面語言皆可切換；三份 resx 資源鍵一致。動態錯誤與確認文字隨語言改變。
- 分類根節點 0 不重複；任意層級可選。選父分類查詢不出現只屬於子分類的文章。
- 新文章：繁中標題必填，日期必填、結束不可早於開始。存檔後僅 Raw 四組資料，無屬性列、狀態待審；Subject/Body 與 ZHTW 一致。
- 首次上架：四組正式資料一次建立，UID/AID/AttID 保持一致，PostDate 更新，預定日期帶入發布日期。
- 預約上架、有效區間、已到期、雙 NULL 及邊界時間分類符合規則。
- 已上架文章儲存修改：Raw 內容更新、兩邊發布日期 NULL；正式內文及附件仍為舊版。
- 再上架：正式內容覆蓋為 Raw，移除的附件不再留於正式表，原有屬性仍保留。
- 下架：兩表發布開始及結束均為相同時間減一天；PostDate 不變。
- 刪除：八張 Raw／正式表均無該文章；kmCategory、圖片目錄未刪除。
- 兩視窗同時開啟同篇文章，第一視窗儲存後第二視窗不能覆蓋；顯示重新載入提示。
- 批次中一筆版本過期：整批回復，其他文章不應部分上架／刪除。
- 上架時模擬正式表限制錯誤：Raw 的狀態及 PostDate 也必須回復。
- 既有多分類文章不會因編輯而丟失分類；同篇重複 AttrName 發布被拒絕。
- 各語系附件 FileLang 正確，FileStatus=OK；取消編輯不刪 Raw 附件。
- 空檔案、超過 10 MiB、執行檔及改副檔名的 MZ 檔被拒絕。
- 圖片合法類型可上傳並插入；同名檔拒絕且原檔不變，含路徑／無效檔名拒絕。
- HTML 中 script、onerror 等不安全內容儲存／重新開啟後不可執行。
- SQL 查詢關鍵字單引號、百分比、底線及中文不造成錯誤或萬用字元誤比對。
- IIS 真實帳號、SQL 憑證、圖片目錄 ACL、前台圖片 URL 及重新部署後圖片保留均確認。
