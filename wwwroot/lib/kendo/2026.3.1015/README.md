# Kendo UI 2026.3.1015

請放入已授權的 Kendo UI for jQuery 2026.3.1015 資源：

```text
js/kendo.all.min.js
js/cultures/kendo.culture.zh-TW.min.js
js/cultures/kendo.culture.zh-CN.min.js
js/cultures/kendo.culture.en-US.min.js
js/messages/kendo.messages.zh-TW.min.js
js/messages/kendo.messages.zh-CN.min.js
js/messages/kendo.messages.en-US.min.js
styles/default-main.css
```

Theme 的字型、圖示等相依檔案也須一併複製。主題樣式檔若名稱不同，請調整 Views/Shared/_Layout.cshtml 的 stylesheet 路徑。
授權啟用方式依公司取得的 Telerik 授權套件處理，不要將授權密鑰放入 wwwroot。
此目錄不附第三方商用程式碼，也不會以其他版本或 CDN 取代。
